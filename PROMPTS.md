# Copy-paste prompts

Start Claude Code in the folder that holds your video (`cd` there, then `claude`). Replace `myvideo.mp4` with your file name.

## The one-shot reel
> Use the video-editing skill. Turn `myvideo.mp4` into a reel: cut silences, add word-highlight captions, export 9:16. Save as `myvideo_reel.mp4`.

## Only remove dead air
> Use the video-editing skill. Remove silences from `myvideo.mp4` but keep it natural, not choppy. Tell me how many seconds you removed.

## Captions in my colors
> Use the video-editing skill. Add captions to `myvideo.mp4`: white text, orange highlight on the spoken word, 3 words per line.

## A hook on top
> Use the video-editing skill. Add the text "3 AI tools I use daily" at the top of `myvideo.mp4` for the first 3 seconds.

## LinkedIn version
> Use the video-editing skill. Make a LinkedIn feed version of `myvideo.mp4`: 4:5, captions on, silences cut.

## Landscape clip into a reel, without chopping the sides
> Use the video-editing skill. Export `myvideo.mp4` as a reel using the blur-background fit so nothing gets cropped.

## Fix a caption mistake
> Use the video-editing skill. Transcribe `myvideo.mp4`, show me the words, let me correct them, then burn the corrected captions.

## Cuts feel too aggressive
> Redo the silence cut on `myvideo.mp4` but gentler: only remove pauses longer than 0.8 seconds and keep 0.2 seconds around speech.

## Make one command for the next time
> Look at the edit we just did and write me a one-line prompt I can reuse for the next video.

**Tip:** one edit at a time beats a giant prompt. Look at the result, then say what to change ("captions lower", "cut less").
